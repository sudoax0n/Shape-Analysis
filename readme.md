# Shape Analysis Tools

A Python based GUI tool used for shape analysis of objects.

Used in Publications:

> #### [1] Shape Analysis of Biomimetic and Plasma Membrane Vesicles
>
> URL: https://chemistry-europe.onlinelibrary.wiley.com/doi/10.1002/syst.202400052
>
> #### [2] Experimentally  Determined Shapes of Plasma Membrane Vesicles, Phosphatidylcholine  (PC), and PC-Cholesterol Vesicles: Vesicle Deflation Analysis Using  Confocal Microscopy
>
> URL: https://pubs.acs.org/doi/full/10.1021/acs.jpcb.4c07431

# Installation

To install, simply clone the repository.

> git clone https://github.com/tanmay1902/Shape-Analysis.git

Then go to the Shape Analysis folder. This program can automatically install dependencies when you first run the program; or you can use:

> pip install -r requirements.txt
